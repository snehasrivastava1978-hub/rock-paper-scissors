# rock-paper-scissors
A console based Rock paper scissors game built as the part of [The Odin Project](https://theodinproject.com) foundations curriculum.
## Live Demo
[Play game here](https://github.com/snehasrivastava1978-hub/rock-paper-scissors.git).
## Built with
* **JavaScript(ES6)** - Game logic, DOM manipulation, and score tracking.
## Features
* Play against the computer with randomized choices (`Rock`, `Paper` and `Scissors`).
* Real-time score tracking for both the player and the computer.
* Player with maximum scores in five rounds will win the game.
* Option to reset and play again once a winner is declared.
## What I learned
* Writing clean, modular javaScript functions(`getcomputerchoice`, `playgame`, `playRound`).
* Managing game state, conditionals and loops.
* Practicing git workflows (staging, committing and pushing changes to GitHub).
